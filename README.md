# Playlist Maker

## Описание проекта

Playlist Maker — Android-приложение для поиска музыкальных треков через API iTunes и создания собственных плейлистов.

Приложение позволяет:
- искать треки по названию или исполнителю;
- просматривать информацию о треке (название, исполнитель, длительность, обложка);
- сохранять треки в избранное;
- создавать плейлисты;
- добавлять треки в плейлисты;
- просматривать содержимое плейлистов;
- удалять плейлисты.

Данные избранных треков и плейлистов сохраняются локально.
